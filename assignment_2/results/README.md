# Results

`dataset_audit.json` is a **data audit** (row counts, label counts, duplicates, overlaps and file hashes)
produced by [`../scripts/audit_dataset.py`](../scripts/audit_dataset.py). It is **not** model performance.

This folder holds the Item 2 results: the dataset audit and the M0 validation baseline (`m0_baseline.json`, `m0_cpu_bench.json`, `dataset_stats.json`).
Item 3 validation results for M0, M1 and M2 are in [`assignment_3/item3_evidence/`](../../assignment_3/item3_evidence/), and the final held-out test results are in [`assignment_4/results/`](../../assignment_4/results/).
